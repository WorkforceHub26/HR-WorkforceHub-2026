ล้างข้อมูลทดสอบก่อนเปิดใช้งานจริง
==================================

ทำวันเดียวกับที่จะเปิดให้พนักงานใช้ (หลังทดสอบเสร็จหมดแล้ว) บนฐานข้อมูลจริง (MAIN)

1) ความยินยอม (PDPA) ที่กดตอนทดสอบ — แนะนำวิธีนี้
   หน้าคอนโซลผู้ดูแลระบบ > ประกาศความเป็นส่วนตัว
   แก้ข้อความ เติมช่อง [ ... ] ให้ครบ (ชื่อผู้ติดต่อ เบอร์ ระยะเวลาเก็บ) แล้วกด "ออกเป็นฉบับที่ 2"
   → ทุกคน รวมถึงคนที่กดตอนทดสอบ จะต้องอ่านและกดยอมรับฉบับจริงใหม่ตอนเข้าระบบครั้งถัดไป
   → ของที่กดตอนทดสอบยังเก็บไว้เป็นประวัติฉบับที่ 1 ไม่มีผลกับการใช้งาน

2) เครื่องที่ตอบ "ใช่ เครื่องของฉัน" / การเข้าระบบค้าง / ลิงก์ LINE ทดสอบ
   Supabase > SQL Editor > วาง supabase/go_live_reset.sql > Run
   → ทุกคนออกจากระบบ เครื่องที่จำไว้ถูกลืม ครั้งหน้าระบบจะถาม "นี่เป็นเครื่องของคุณใช่ไหม?" ใหม่
   → ไม่ลบข้อมูลพนักงาน รหัสผ่าน HR/Admin ใบลา โควตา สายอนุมัติ
   ผลบรรทัดสุดท้าย: sessions_active, devices_remembered, line_links_unused, login_attempts = 0

   ข้อ 2 ในไฟล์ (ลบการยอมรับ PDPA ตอนทดสอบทิ้งเลย) ปิดไว้ ใช้เฉพาะกรณีไม่อยากเห็นประวัติทดสอบ
   และยังไม่มีพนักงานจริงคนไหนกดยอมรับ — ลบเอาเครื่องหมาย -- หน้า 5 บรรทัดนั้นออกก่อนรัน

3) ใบลาที่ยื่นตอนทดสอบ ไฟล์นี้ไม่ได้ลบให้ (มีผลกับโควตาวันลา) — ถ้ามี แจ้งรหัสพนักงานที่ใช้ทดสอบมา จะทำสคริปต์แยกให้





เอาปุ่มเข้าสู่ระบบด้วยลายนิ้วมือ / ใบหน้าออก
=============================================

วางไฟล์ทับของเดิม (ไม่มี SQL):
  index.html          ← รวมการแก้หน้าสแกน QR (WFH-qr-simple) ไว้แล้ว ใช้ตัวนี้
  auth/index.js       ← รวมการแก้หน้าสแกน QR ไว้แล้ว ใช้ตัวนี้
  public/sw.js        ← ใช้ตัวนี้แทนตัวในไฟล์ zip ก่อนหน้าทั้งหมด
  CLEANUP_NOTES.md    ← ใช้ตัวนี้แทนตัวในไฟล์ zip ก่อนหน้าทั้งหมด
แล้วเปิดหน้าใหม่ (Ctrl+F5)

ผล: หน้าเข้าสู่ระบบ > "เข้าสู่ระบบวิธีอื่น" เหลือแค่ สแกนคิวอาร์โค้ดบัตรพนักงาน + วิธีถือบัตรสแกน
