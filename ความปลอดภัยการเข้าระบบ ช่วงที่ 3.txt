ความปลอดภัยการเข้าระบบ ช่วงที่ 3 — กดอนุมัติจาก LINE ได้เลย ไม่ต้องใส่รหัส
=========================================================================

ผู้อนุมัติจะเห็นอะไร
- ข้อความ LINE ใบลารออนุมัติ หน้าตาเหมือนเดิม (ปุ่ม อนุมัติ / ไม่อนุมัติ)
- กดปุ่ม → เข้าระบบในบัญชีของตัวเองอัตโนมัติ → เปิดใบลานั้น → กดยืนยันอีกครั้งเดียว เสร็จ
- เครื่องที่เปิดจาก LINE ถือเป็นเครื่องของผู้อนุมัติ (ถ้ายังไม่มีเจ้าของ) จำไว้ 90 วัน
- ลิงก์ใช้ได้ครั้งเดียว อายุ 3 วัน
    กดซ้ำ / หมดอายุ → ถ้าเครื่องนี้เข้าระบบอยู่แล้ว เปิดใบลาเลย · ถ้ายังไม่ได้เข้า ระบบให้ล็อกอินแล้วพาไปที่ใบลาเดิม
    ใบลาพิจารณาไปแล้ว (คนอื่นกดก่อน / ผู้ยื่นยกเลิก) → แจ้งให้ทราบ แล้วเปิดให้ดูรายละเอียด

ความปลอดภัย
- ลิงก์ถูกสร้างฝั่งเซิร์ฟเวอร์ (Edge Function line-send) เฉพาะตอนส่งถึงผู้อนุมัติของลำดับที่รออยู่จริง
  คนยื่นใบลาไม่เห็นลิงก์ จึงกดอนุมัติใบลาของตัวเองไม่ได้
- ⚠️ แจ้งผู้อนุมัติ: อย่าส่งต่อ (forward) ข้อความแจ้งเตือนใบลาให้คนอื่น — คนที่กดลิงก์ก่อนจะเข้าบัญชีผู้อนุมัติได้
  (ถ้าเกิดขึ้น HR กด "ล้างเครื่องที่จำไว้ + ออกจากระบบทุกเครื่อง" ให้ผู้อนุมัติคนนั้น)

ลำดับติดตั้ง
1) อัปโหลดไฟล์หน้าเว็บในชุดนี้
2) รัน supabase/migrations/20261025_auth_phase3_line_links.sql ใน SQL Editor ที่ DEV
   (ต้องรันช่วง 1 และ 2 แล้ว) ผลตรวจ functions_ready ต้องเป็น 2
3) Deploy Edge Function ใหม่ (ที่โปรเจกต์ DEV):
     supabase functions deploy line-send
   หรือ Supabase Dashboard > Edge Functions > line-send > วางโค้ดจาก supabase/functions/line-send/index.ts แล้ว Deploy
   (ใช้ค่า SUPABASE_URL และ SUPABASE_SERVICE_ROLE_KEY ที่ Supabase ใส่ให้อัตโนมัติ ไม่ต้องตั้งเพิ่ม)
4) ทดสอบบน DEV
   - พนักงานยื่นใบลา → ผู้อนุมัติได้ LINE → กด "อนุมัติ" ในแอป LINE → เปิดใบลาโดยไม่ต้องล็อกอิน → ยืนยัน
   - กดปุ่มเดิมซ้ำ → ไปที่ใบลา (เข้าระบบอยู่แล้ว)
5) ผ่านแล้วทำข้อ 2–3 ที่ MAIN

ข้อควรรู้
- ข้อความที่ส่งก่อนอัปเดต หรือส่งผ่านเซิร์ฟเวอร์สำรอง (/api/send-notification) ไม่มีลิงก์ใช้ครั้งเดียว
  → กดแล้วให้ล็อกอินตามปกติ แล้วพาไปที่ใบลา
