PVT Workforce Hub — ปุ่ม "ใบลารออนุมัติ" ที่หน้าหลักพนักงาน (pvt_apbtn.zip)
=========================================================================
ไฟล์นี้ "แทน" pvt_linepending.zip (รวมการแก้ LINE ไม่ส่ง + Dev/Main แยกฐาน ไว้ครบแล้ว) — ใช้ไฟล์นี้ไฟล์เดียว

ของใหม่
1) หน้าหลักพนักงาน (index-user) มีปุ่ม "ใบลารออนุมัติ" ใต้ปุ่ม "ยื่นใบลาออนไลน์"
   - แสดงเฉพาะคนที่มีหน้าที่อนุมัติ (อยู่ในสายอนุมัติ / เป็นหัวหน้า-ผู้จัดการแผนก / มีใบลารอตัวเอง)
     พนักงานทั่วไปไม่เห็นปุ่มนี้
   - ป้ายแดงที่ไอคอน = จำนวนใบลาที่รอท่านพิจารณาตอนนี้ (อัปเดตเองทุก 1 นาที และเมื่อกลับมาที่หน้า)
   - ไม่มีใบลารอ → ปุ่มยังอยู่ แสดง "ไม่มีใบลารอพิจารณา"
   - กดแล้วไปหน้าอนุมัติใบลา แท็บ "รออนุมัติ"
2) (จากชุดก่อน) การ์ด LINE มีปุ่ม "ใบลารออนุมัติ" + เปิดลิงก์แล้วไม่พบใบลาจะขึ้นแจ้งแทนการเงียบ
